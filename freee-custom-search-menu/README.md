# freee会計 Ctrl+右クリック カスタム検索メニュー

freee会計の画面で文字列や金額を選択して **Ctrl+右クリック** すると、選択した内容で取引・明細・仕訳帳などを検索できるメニューを表示するTampermonkeyユーザースクリプトです。

> **β版です。**  
> freee会計の取引画面が新画面へ切り替わっている最中のため、一時的にうまく動かない場面があるかもしれません。ご了承ください。

## 背景

freee会計で「この金額の明細はどこにある？」「この取引先の取引を全部見たい」と思ったとき、検索画面を開いて条件を入力し直す手間がかかります。  
画面上の文字列や金額を選んでそのまま検索できれば、その手間がなくなります。

## インストール

[Raw URLはこちら](https://raw.githubusercontent.com/eustacia-jp/tampermonkey-scripts/main/freee-custom-search-menu/freee-custom-search-menu.user.js)

[Tampermonkey](https://www.tampermonkey.net/) 拡張機能が導入済みのブラウザで上記リンクを開くと、インストール確認画面が表示されます。  
一度インストールすると、以降は自動的に最新版にアップデートされます。

## できること

freee会計の画面で文字列や金額を選択し、Ctrl+右クリックすると、次のメニューが表示されます。  
選択した文字列は、文字列として使う項目（緑の <code>A</code> アイコン）と、数字だけを取り出して金額として使う項目（赤橙の <code>¥</code> アイコン）に振り分けられます。

| グループ | メニュー | 開く画面 |
|---|---|---|
| 取引 | 取引 - 取引内容 | 取引一覧を、明細上の取引内容（摘要）で検索 |
| | 取引 - 備考 | 取引一覧を、備考（明細行の備考）で検索 |
| | 取引 - 取引先 | 取引一覧を、取引先で検索 |
| マスタ | マスタ - 取引先 | 取引先マスタを検索 |
| 明細 | 自動で経理 - 金額 / 文字列 | 「自動で経理」で、同額の明細・摘要が一致する明細を検索 |
| | 明細の一覧 - 金額 / 文字列 | 「明細の一覧」で、同額の明細・摘要が一致する明細を検索 |
| 仕訳帳 | 仕訳帳 - 金額 | 仕訳帳を同額で検索 |
| ヘルプ | ヘルプセンター | freeeヘルプセンターを検索 |

メニューは意味のまとまりごとに背景色が分かれています（取引・明細・仕訳帳＝薄い青、マスタ・ヘルプ＝薄い緑）。

### 新画面・旧画面の両方に対応

取引の検索は、利用している画面（新画面 `/deals/standards`、旧画面 `/deals`）を自動で判定して、それぞれに合ったURLで開きます。  
「取引 - 取引先」では、新画面で必要になる取引先IDをfreeeから取得して検索します。

### 「自動で経理」と「明細の一覧」の使い分け

「自動で経理」は、取引日を空欄にして検索しても現在の会計期間より前の明細は表示されません。  
過去の明細を調べたいときは「明細の一覧」を使ってください。URLで開いた直後は現在の会計期間で絞り込まれているので、取引日を空欄にして「絞り込み」をクリックし直すと、過去の明細も表示されます。

## そのほかの機能

- 取引先マスタの取引先詳細画面に、「[旧] 取引を検索」「[新] 取引を検索」ボタンを追加します。押すと、その取引先の取引が新旧それぞれの画面で開きます

## 必要な権限について

このスクリプトは以下の権限を使用しています。

| 権限 | 用途 |
|---|---|
| `GM_openInTab` | 検索結果を新しいタブで開くため |
| `GM_addStyle` | メニューのスタイルを適用するため |
| `GM_xmlhttpRequest` | 他のfreee画面（請求書など）から取引先IDを取得するため |

初めて実行するときに、Tampermonkeyから「外部サイト（freee内）へのアクセスを許可しますか？」という確認が表示される場合があります。その場合は「常に許可」を選んでください。
