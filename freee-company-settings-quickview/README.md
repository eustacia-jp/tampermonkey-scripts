# freee事業所設定クイックビュー

freee会計にログイン中、画面上部に常時表示されるボタンから、いま開いている事業所の基本情報・消費税・インボイス関連設定などをその場で一覧確認できるTampermonkeyスクリプトです。

複数の事業所にアドバイザーとしてログインする機会が多いと、「この事業所は一般課税だったか簡易課税だったか」「少額特例の対象だったか」「インボイスの登録番号はあったか」「設定はきちんとできているか」などを確認したい場面があると思います。  
そのたびに設定画面を開いて確認する手間を省くために作りました。

表示された情報をまとめてコピーすることもできます。

※初回実行時は情報の取得に時間がかかり、すべての項目を表示できない場合があります。その際は再取得してみてください。

## インストール

[Raw URLはこちら](https://raw.githubusercontent.com/eustacia-jp/tampermonkey-scripts/main/freee-company-settings-quickview/freee-company-settings-quickview.user.js)

[Tampermonkey](https://www.tampermonkey.net/) 拡張機能が導入済みのブラウザで上記リンクを開くと、インストール確認画面が表示されます。

## できること

freee会計の画面最上部に表示されるボタンを押すと、以下の情報をパネルにまとめて表示します。

**基本情報**
- 業種、法人番号（国税庁サイトへの検索リンク付き）、決算月、住所（簡易・詳細）

**消費税**
- 課税方式、簡易課税の事業区分（みなし仕入率つき）、消費税の経理処理、消費税の端数処理

**インボイス制度関連**
- 買い手側対応、少額特例の一括修正、少額特例の対象事業者、登録番号（国税庁の公表サイトへの検索リンク付き）
- 課税方式や買い手側対応の設定によっては、実質的に意味を持たない項目を自動で「―」表示にします
- 標準的でない組み合わせ（免税なのに税抜経理、など）には、目印としてアイコンを表示します

**アカウント管理**
- 事業所作成者

## そのほかの機能

- 各項目名をクリックすると、対応するfreeeの設定編集画面を新しいタブで開きます
- パネル右上のアイコンから、表示内容のコピー（タブ区切り）、情報の再取得、表示設定の変更ができます
- 一度取得した情報は24時間キャッシュされ、次回はキャッシュから即座に表示します（スクリプトが更新された場合は自動的にキャッシュを破棄して再取得します）
- 常時表示ボタンの位置は、表示設定から「左端からの距離（px）」を指定できます（freeeのグローバルナビゲーションと重ならない位置に調整することを想定しています）

## 必要な権限について

このスクリプトは以下の権限を使用しています。

| 権限 | 用途 |
|---|---|
| `unsafeWindow` | freeeページに埋め込まれている事業所情報（`freee.data`）を読み取るため |
| `GM_xmlhttpRequest` | 別ドメイン（`accounts.secure.freee.co.jp`）にある登録番号・事業所作成者などの情報を取得するため |
| `GM_cookie` | 上記リクエストに必要なCSRFトークンをCookieから読み取るため |
| `GM_setValue` / `GM_getValue` | 取得結果のキャッシュと、表示設定の保存のため |
| `GM_info` | インストール済みスクリプトのバージョンを判定し、更新時にキャッシュを破棄するため |

## 注意事項

- 本スクリプトはfreeeの非公開・非公式なページ構造や内部APIに依存している部分があります。freee側の仕様変更により、予告なく一部または全部が動作しなくなる可能性があります
- 自己責任でご利用ください
- 表示される内容はあくまで参考情報です。正式な設定および情報の確認はご自身で行うようにしてください
